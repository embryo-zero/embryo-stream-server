# Embryo Stream Server

Embryo Stream Server is Embryo-Zero's fork of [MediaMTX](https://github.com/bluenviron/mediamtx) (42e79d0, commit 42e79d0). It does live stream server (RTMP, WebRTC, HLS).

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
